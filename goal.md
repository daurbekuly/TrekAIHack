# Цель проекта

**Помочь маленькому магазину (SME) в Таразе заказывать у поставщиков ровно столько, сколько продастся, без пустых полок и без залежавшегося товара.**

Владелец каждое утро получает в Telegram готовый список: что заканчивается, что лежит лишнее и сколько штук заказать. Одна кнопка, и заказ уходит дистрибьютору в WhatsApp.

---

## Проблема

1. Владелец заказывает «на глаз», поэтому одни товары заканчиваются, а другие пылятся на складе.
2. Не все продажи проходят через кассу: часть товара уходит «мимо кассы» (теневые продажи). Если прогнозировать только по кассе, спрос получится заниженным и товар закончится.
3. У владельца нет времени разбираться в отчётах. Ему нужно короткое сообщение с готовыми цифрами.

## Как это работает

```
Касса (продажи) ─┐
Накладные ───────┼─► 1. Сверка остатков ─► 2. Прогноз спроса ─► 3. Расчёт заказа ─► 4. Telegram
Ревизии ─────────┘     (теневые продажи)     (Prophet)            (код, не ИИ)        + WhatsApp
```

| Шаг | Что происходит | Где в коде |
|---|---|---|
| **1. Сверка** | `Продано на самом деле = Остаток на начало + Приход по накладным − Остаток на конец`. Разница с кассой — это **теневые продажи**. Они распределяются по дням с учётом дня недели и добавляются к истории продаж. | `app/services/discrepancy_service.py` |
| **2. Прогноз** | Для каждого товара Prophet прогнозирует продажи на 7 дней вперёд, учитывая дни недели и праздники Казахстана. Если истории мало, используется простая статистическая модель. | `app/services/ai_forecasting_service.py` |
| **3. Заказ** | Код сравнивает прогноз с остатком: 🔴 скоро закончится, 🟡 нужно пополнить, 🔵 излишек. Количество к заказу считается так, чтобы спроса хватило с вероятностью ~90%. | `app/services/ai_forecasting_service.py` |
| **4. Сообщение** | ИИ (OpenAI) превращает цифры в понятное сообщение. **Все числа считает код, ИИ только пишет текст.** Если ИИ недоступен, отправляется готовый шаблон. | `app/services/ai_forecasting_service.py` |
| **5. Telegram** | Каждый день в 08:00 и по команде `/forecast` бот присылает отчёт. Кнопка **«✅ Тапсырысты растау / WhatsApp-қа жіберу»** подтверждает заказ и открывает WhatsApp с готовым текстом для дистрибьютора. | `app/bot.py`, `app/main.py` |

**Подключение магазина:** администратор выдаёт одноразовую ссылку (`POST /stores/{id}/telegram-link`). Владелец открывает её в Telegram, и бот привязывается к его магазину. Подключить чужой магазин без ссылки нельзя.

## Технологии

Python 3.10+ · FastAPI · PostgreSQL (локально или Neon) · SQLAlchemy + Alembic · Pandas · Prophet · OpenAI API · aiogram 3 · APScheduler

## Быстрый старт

Подробная инструкция в [README.md](README.md). Коротко:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env          # заполнить DATABASE_URL, TELEGRAM_BOT_TOKEN, ADMIN_API_KEY
alembic revision --autogenerate -m "initial schema"
alembic upgrade head
python -m scripts.seed_demo     # демо-магазин
uvicorn app.main:app --reload
```
